# Contributing

This is a small documentation repository. Keep it that way.

1. Edit or add a Markdown page under `docs/`.
2. Add the page to `nav` in `mkdocs.yml`.
3. Say what you verified. Use `status: draft` if you did not run the commands.
4. Run `bash scripts/check.sh` before opening a pull request.

Do not publish credentials, personal data, or sensitive operational details.
AI agents should read [`AGENTS.md`](AGENTS.md) first.

For how to read and add pages, see
[`docs/using-the-knowledge-base.md`](docs/using-the-knowledge-base.md).
For how the site works as team memory and AI context, see
[`docs/team-memory.md`](docs/team-memory.md).
